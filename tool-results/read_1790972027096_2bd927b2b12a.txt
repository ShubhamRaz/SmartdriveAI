    58→  1008→## Auto-Generated Table of Contents
    59→  1009→
    60→  1010→### ❌ FORBIDDEN: Manual Table of Contents
    61→  1011→**NEVER manually create TOC with hardcoded page numbers.**
    62→  1012→
    63→  1013→### ⚠️ MANDATORY: TOC requires a cover page
    64→  1014→**Unless the user explicitly requests no cover, if a document has a Table of Contents, it MUST have a cover page.** Structure: Cover (page 1) → TOC (page 2) → Content (page 3+). Do not generate a TOC without a preceding cover page.
    65→  1015→
    66→  1016→### ✅ ALWAYS use auto-generated TOC:
    67→  1017→
    68→  1018→```python
    69→  1019→from reportlab.platypus import SimpleDocTemplate, Paragraph, PageBreak, Spacer
    70→  1020→from reportlab.platypus.tableofcontents import TableOfContents
    71→  1021→from reportlab.lib.utils import simpleSplit
    72→  1022→import hashlib
    73→  1023→
    74→  1024→class TocDocTemplate(SimpleDocTemplate):
    75→  1025→    def afterFlowable(self, flowable):
    76→  1026→        if hasattr(flowable, 'bookmark_name'):
    77→  1027→            level = getattr(flowable, 'bookmark_level', 0)
    78→  1028→            text = getattr(flowable, 'bookmark_text', '')
    79→  1029→            key = getattr(flowable, 'bookmark_key', '')
    80→  1030→            # MUST pass key as 4th element - without it, TOC entries won't have clickable links
    81→  1031→            self.notify('TOCEntry', (level, text, self.page, key))
    82→  1032→
    83→  1033→doc = TocDocTemplate("document.pdf", pagesize=letter)
    84→  1034→story = []
    85→  1035→
    86→  1036→toc = TableOfContents()
    87→  1037→toc.levelStyles = [
    88→  1038→    ParagraphStyle(name='TOCHeading1', fontSize=14, leftIndent=20, fontName='FreeSerif'),
    89→  1039→    ParagraphStyle(name='TOCHeading2', fontSize=12, leftIndent=40, fontName='FreeSerif'),
    90→  1040→]
    91→  1041→story.append(Paragraph("<b>Table of Contents</b>", styles['Title']))
    92→  1042→story.append(toc)
    93→  1043→story.append(PageBreak())
    94→  1044→
    95→  1045→def add_heading(text, style, level=0):
    96→  1046→    # Generate a unique bookmark key for this heading
    97→  1047→    key = 'h_%s' % hashlib.md5(text.encode()).hexdigest()[:8]
    98→  1048→    p = Paragraph('<a name="%s"/>%s' % (key, text), style)
    99→  1049→    p.bookmark_name = text
   100→  1050→    p.bookmark_level = level
   101→  1051→    p.bookmark_text = text
   102→  1052→    p.bookmark_key = key  # This key enables clickable TOC links
   103→  1053→    return p
   104→  1054→
   105→  1055→# ⚠️ Orphan Heading Prevention (NOT a page break rule)
   106→  1056→# If an H1 heading would appear in the bottom 15% of the page with no room
   107→  1057→# for at least a few lines of content, push it to the next page.
   108→  1058→# This is NOT "every H1 starts a new page" — it only triggers when the heading
   109→  1059→# would be orphaned at the very bottom.
   110→  1060→available_height = A4[1] - top_margin - bottom_margin
   111→  1061→H1_ORPHAN_THRESHOLD = available_height * 0.15  # ~100pt ≈ 3.5cm — enough for heading + 2 lines
   112→  1062→
   113→  1063→def add_major_section(text, style):
   114→  1064→    """Add an H1-level heading with orphan prevention (NOT forced page break)."""
   115→  1065→    return [
   116→  1066→        CondPageBreak(H1_ORPHAN_THRESHOLD),  # Only break if heading would be orphaned at page bottom
   117→  1067→        add_heading(text, style, level=0),
   118→  1068→    ]
   119→  1069→
   120→  1070→story.extend(add_major_section("Chapter 1: Introduction", styles['Heading1']))
   121→  1071→# ... content ...
   122→  1072→
   123→  1073→doc.multiBuild(story)  # MUST use multiBuild for TOC
   124→  1074→```
   125→  1075→
   126→  1076→**⚠️ CRITICAL TOC LINK RULES:**
   127→  1077→1. `afterFlowable` MUST pass `key` as the 4th element in the notify tuple - without it, TOC entries have no clickable links
   128→  1078→2. `add_heading` MUST set `bookmark_key` AND embed `<a name="key"/>` in the Paragraph text - this creates the link destination
   129→  1079→3. The key must be unique per heading - use a hash of the heading text

   131→  1081→### TOC with Leader Dots (Copy-Paste Ready)
   132→  1082→
   133→  1083→**⚠️ WARNING**: This manual approach creates a visual-only TOC. It has **NO clickable links** and **NO auto-updated page numbers**. Use the auto-generated TOC above (TocDocTemplate + multiBuild) whenever possible. Only use this leader-dots approach if you need very specific visual styling that the auto TOC cannot provide - and even then, prefer the auto approach.
   134→  1084→
   135→  1085→For a professional TOC with leader dots connecting titles to page numbers:
   136→  1086→
   137→  1087→```python
   138→  1088→from reportlab.lib.pagesizes import A4
   139→  1089→from reportlab.platypus import SimpleDocTemplate, Table, TableStyle, Paragraph, PageBreak
   140→  1090→from reportlab.lib.styles import getSampleStyleSheet, ParagraphStyle
   141→  1091→from reportlab.lib import colors
   142→  1092→from reportlab.lib.units import inch
   143→  1093→
   144→  1094→# Setup
   145→  1095→doc = SimpleDocTemplate("report.pdf", pagesize=A4,
   146→  1096→                       leftMargin=0.75*inch, rightMargin=0.75*inch)
   147→  1097→styles = getSampleStyleSheet()
   148→  1098→styles['Heading1'].fontName = 'FreeSerif'
   149→  1099→styles['Heading1'].textColor = colors.black
   150→  1100→
   151→  1101→story = []
   152→  1102→
   153→  1103→# Calculate dimensions
   154→  1104→page_width = A4[0]
   155→  1105→available_width = page_width - 1.5*inch
   156→  1106→page_num_width = 50  # Fixed width for page numbers
   157→  1107→dots_column_width = available_width - 200 - page_num_width
   158→  1108→optimal_dot_count = int(dots_column_width / 4.5)  # ~4.5pt per dot at 7pt font
   159→  1109→
   160→  1110→# Define styles
   161→  1111→toc_style = ParagraphStyle('TOCEntry', parent=styles['Normal'],
   162→  1112→                          fontName='FreeSerif', fontSize=11, leading=16)
   163→  1113→dots_style = ParagraphStyle('LeaderDots', parent=styles['Normal'],
   164→  1114→                           fontName='FreeSerif', fontSize=7, leading=16)
   165→  1115→
   166→  1116→# Build TOC
   167→  1117→toc_data = [
   168→  1118→    [Paragraph('<b>Table of Contents</b>', styles['Heading1']), '', ''],
   169→  1119→    ['', '', ''],
   170→  1120→]
   171→  1121→
   172→  1122→entries = [('Section 1', '5'), ('Section 2', '10')]
   173→  1123→for title, page in entries:
   174→  1124→    toc_data.append([
   175→  1125→        Paragraph(title, toc_style),
   176→  1126→        Paragraph('.' * optimal_dot_count, dots_style),
   177→  1127→        Paragraph(page, toc_style)
   178→  1128→    ])
   179→  1129→
   180→  1130→toc_table = Table(toc_data, colWidths=[None, dots_column_width, page_num_width])
   181→  1131→toc_table.setStyle(TableStyle([
   182→  1132→    ('GRID', (0, 0), (-1, -1), 0, colors.white),
   183→  1133→    ('LINEBELOW', (0, 0), (0, 0), 1.5, colors.black),
   184→  1134→    ('ALIGN', (0, 0), (0, -1), 'LEFT'),
   185→  1135→    ('ALIGN', (1, 0), (1, -1), 'LEFT'),
   186→  1136→    ('ALIGN', (2, 0), (2, -1), 'RIGHT'),
   187→  1137→    ('VALIGN', (0, 0), (-1, -1), 'TOP'),
   188→  1138→    ('LEFTPADDING', (0, 0), (-1, -1), 0),
   189→  1139→    ('RIGHTPADDING', (0, 0), (-1, -1), 0),
   190→  1140→    ('TOPPADDING', (0, 2), (-1, -1), 3),
   191→  1141→    ('BOTTOMPADDING', (0, 2), (-1, -1), 3),
   192→  1142→    ('TEXTCOLOR', (1, 2), (1, -1), TEXT_MUTED),  # From palette --c-muted
   193→  1143→]))
   194→  1144→
   195→  1145→story.append(toc_table)
   196→  1146→story.append(PageBreak())
   197→  1147→doc.build(story)
   198→  1148→```
   199→  1149→

   232→  1182→```python
   233→  1183→class CrossReferenceDocument:
   234→  1184→    def __init__(self):
   235→  1185→        self.figures = {}
   236→  1186→        self.tables = {}
   237→  1187→        self.refs = {}
   238→  1188→        self.figure_counter = 0
   239→  1189→        self.table_counter = 0
   240→  1190→        self.ref_counter = 0
   241→  1191→
   242→  1192→    def add_figure(self, name):
   243→  1193→        if name not in self.figures:
   244→  1194→            self.figure_counter += 1
   245→  1195→            self.figures[name] = self.figure_counter
   246→  1196→        return self.figures[name]
   247→  1197→
   248→  1198→    def add_table(self, name):
   249→  1199→        if name not in self.tables:
   250→  1200→            self.table_counter += 1
   251→  1201→            self.tables[name] = self.table_counter
   252→  1202→        return self.tables[name]
   253→  1203→
   254→  1204→    def add_reference(self, name):
   255→  1205→        if name not in self.refs:
   256→  1206→            self.ref_counter += 1
   257→  1207→            self.refs[name] = self.ref_counter
   258→  1208→        return self.refs[name]
   259→  1209→```

   265→  1215→### Diagram Embedding Rules (MANDATORY)
   266→  1216→
   267→  1217→**Figures are block-level Flowables.** Every image/diagram in ReportLab MUST be appended to `story` as a standalone `Image()` or wrapped in `KeepTogether([image, caption])`. Never simulate floating layouts by placing images inside Paragraph text or multi-column Table cells alongside body text.
   268→  1218→

   270→  1220→
   271→  1221→**Diagram quality**: When generating flowcharts/diagrams for PDF embedding (via Playwright screenshot or ReportLab Drawing), follow the diagram content quality rules in SKILL.md § "Diagram Content Quality Rules". Key points: connectors must not pass through nodes, no high-saturation large fills, multi-arrow convergence must use merge pattern, font sizes must be legible at final embedded size (see context-specific minimums in SKILL.md).
   272→  1222→
   273→  1223→**Cross-brief diagram pipeline**: For flowcharts/architecture diagrams, generate via **Playwright+CSS** (HTML nodes + CSS layout + SVG connectors), screenshot at 2× device scale factor for 300dpi print quality, then embed with `Image()`. See SKILL.md § "Diagram Generation Strategy" for the full pipeline.
   274→  1224→
   275→  1225→**🚫 FORBIDDEN: TikZ standalone → PNG pipeline in Report brief.** Report uses ReportLab, not LaTeX. Going through TikZ requires a LaTeX compiler, adds compilation steps, and models frequently produce broken TikZ code. Use Playwright+CSS instead - it's native to the existing cover rendering engine.

   285→  1235→```
   286→  1236→
   287→  1237→**⚠️ CRITICAL: Preserve aspect ratio - NEVER hardcode both width and height without reading actual image dimensions.**
   288→  1238→
   289→  1239→**⚠️ CRITICAL: Always constrain to available space - NEVER insert at original size if it exceeds container width/height.**
   290→  1240→
   291→  1241→Pie charts become ellipses, radar charts become diamonds, photos get stretched if you set arbitrary width/height.
   292→  1242→
   293→  1243→**→ MUST READ: `typesetting/overflow.md`** — read the complete bounding box system before writing layout code.
   294→  1244→
   295→  1245→```python
   296→  1246→from PIL import Image as PILImage
   297→  1247→from reportlab.platypus import Image
   298→  1248→from reportlab.lib.pagesizes import A4
   299→  1249→from reportlab.lib.units import inch
   300→  1250→
   301→  1251→def embed_image(path: str, max_width: float = None, max_height: float = None) -> Image:
   302→  1252→    """Embed image with preserved aspect ratio, constrained to container.
   303→  1253→
   304→  1254→    ALWAYS use this pattern. Never hardcode both width and height.
   305→  1255→    If max_width is None, defaults to available_width (page - margins).
   306→  1256→    """
   307→  1257→    if max_width is None:
   308→  1258→        max_width = A4[0] - 2.0 * inch  # Default: A4 width minus 1" margins each side
   309→  1259→    if max_height is None:
   310→  1260→        max_height = A4[1] * 0.35  # ~294pt ≈ 10cm — leaves room for caption + surrounding text on same page
   311→  1261→
   312→  1262→    pil_img = PILImage.open(path)
   313→  1263→    orig_w, orig_h = pil_img.size
   314→  1264→
   315→  1265→    # Scale to fit within BOTH max_width and max_height
   316→  1266→    ratio_w = max_width / orig_w if orig_w > max_width else 1.0
   317→  1267→    ratio_h = max_height / orig_h if orig_h > max_height else 1.0
   318→  1268→    ratio = min(ratio_w, ratio_h)
   319→  1269→
   320→  1270→    return Image(path, width=orig_w * ratio, height=orig_h * ratio)
   321→  1271→
   322→  1272→# Usage:
   323→  1273→available_width = A4[0] - left_margin - right_margin
   324→  1274→img = embed_image('chart.png', max_width=available_width, max_height=300)
   325→  1275→story.append(img)
   326→  1276→```
   327→  1277→
   328→  1278→```python
   329→  1279→# ❌ NEVER do this - distorts the image:
   330→  1280→img = Image('chart.png', width=400, height=250)  # arbitrary height breaks aspect ratio
   331→  1281→```

   566→  1516→#### Option Layout Decision
   567→  1517→```python
   568→  1518→def format_options(options):
   569→  1519→    """
   570→  1520→    Decide option layout based on content length.
   571→  1521→    Short options (≤4 chars each, ≤4 options) → 2×2 grid table
   572→  1522→    Long options or >4 options → vertical list, one per line
   573→  1523→    """
   574→  1524→    max_len = max(len(opt) for opt in options)
   575→  1525→    if len(options) <= 4 and max_len <= 6:  # CJK: 4 chars; Latin: 6 chars
   576→  1526→        # 2×2 grid using Table
   577→  1527→        grid = Table(
   578→  1528→            [[options[0], options[1]], [options[2], options[3]]],
   579→  1529→            colWidths=[200, 200], hAlign='LEFT'
   580→  1530→        )
   581→  1531→        grid.setStyle(TableStyle([
   582→  1532→            ('LEFTPADDING', (0,0), (-1,-1), 24),  # Match option indent
   583→  1533→            ('VALIGN', (0,0), (-1,-1), 'TOP'),
   584→  1534→        ]))
   585→  1535→        return grid
   586→  1536→    else:
   587→  1537→        # Vertical list
   588→  1538→        return [Paragraph(f'{opt}', option_style) for opt in options]
   589→  1539→```

   632→  1582→
   633→  1583→Before writing ANY body paragraph, scan the text. If you find any of these patterns, extract them:
   634→  1584→
   635→  1585→| Raw text pattern | ❌ FORBIDDEN | ✅ REQUIRED visual form |
   636→  1586→|-----------------|-------------|----------------------|

   638→  1588→| "latency dropped from 120ms to 75ms" | Long explanatory sentence | CalloutBox or metrics table row |
   639→  1589→| "Q1→Q2→Q3: 10%→25%→40%" | Inline numbers in text | Chart (matplotlib PNG → `Image()`) |

   641→  1591→| "compared to last year / vs Q2" | Nested comparisons in prose | Side-by-side comparison table |
